# Prospective 2x2 robot-versus-object hybrid protocol

Status: prospective secondary fallback frozen after observing natural-pair
availability, but before observing any hybrid intervention outcome.

## Motivation and claim boundary

The primary natural-pair protocol requires policy-sampled futures that vary an
object while ending at closely matched robot poses. Early availability pools
showed millimeter-scale, coupled robot/object variation and no registered pair.
Thresholds will not be relaxed. This secondary study constructs a 2x2 endpoint
factorization using LIBERO's public MuJoCo state and renderer.

The result can test whether task-world pixels have an effect after visible robot
state is held fixed. Because two cells combine state components that were not
jointly generated by the policy, this study cannot establish on-distribution
natural-future sufficiency by itself and remains secondary even if positive.

## Natural anchors and candidate selection

The units, deterministic prefix trajectory, and candidate order are inherited
unchanged from `libero_content_factorization_v1`. For each unit, the first
candidate is used whose native 16-step chunk changes the task-world goal vector
by at least 0.003 and changes at least one robot component by the registered
floor: 0.003 m end-effector position, 0.03 radians orientation, or 0.003 gripper
L2. Selection reads no intervention outcome.

The saved state immediately before the chunk is cell O0R0. Executing the native
seed-503 action gives O1R1. Both are natural endpoints connected by the released
policy's action from the exact saved state.

## Counterfactual rendering

Two hybrids are constructed from robosuite's flattened `MjSimState`, whose
public layout is time, qpos, and qvel. Robot arm and gripper indices come from
robosuite's public robot references. O1R0 copies robot qpos and qvel from O0R0
into the O1R1 state; O0R1 makes the reciprocal copy. LIBERO calls
`set_state_from_flattened`, `sim.forward`, and its normal observation renderer.
No physics relaxation step is taken.

Goal features and official nine-dimensional proprioception must reproduce their
intended factor within 1e-9 and 1e-6, respectively. Nonfinite states fail.
Contact counts and all rendered views are retained for auditing. In each object
toggle (O0R0 versus O1R0, and O0R1 versus O1R1), robot pose and wrist-camera
viewpoint are identical. In each robot toggle, non-robot generalized coordinates
are identical.

## Interventions and controls

The released Cosmos tokenizer encodes all four rendered cells into the future
primary-image, wrist-image, and proprioception latent slots. Each clean target is
clamped through every denoiser evaluation while current observation, instruction,
recipient action noise, value noise, schedule, and solver remain fixed. The
future-noise seeds are 1201, 1213, and 1217. The primary analysis clamps all
future modalities. Per-modality clamps, an unclamped native action, and a
recipient-distance/norm-matched Gaussian target are secondary controls. Decoded
future similarity is a mandatory manipulation check.

## Factorial estimands

Every saved action is executed for 16 steps from the exact branch state. Let
Y_goal(O,R) be executed task-world donor steering from the natural current goal
to the natural future goal. The primary object-content estimand is:

`0.5 * [(Y_goal(1,0) - Y_goal(0,0)) + (Y_goal(1,1) - Y_goal(0,1))]`.

The robot main effect uses the analogous contrast on executed robot donor
steering. Cross-effects ask whether robot content changes goal execution and
whether object content changes robot execution. The difference of differences
is reported for both endpoints. Target-cell endpoint identification tests
whether execution is closest to its own factorized target rather than merely
different from O0R0.

Saved state is the cluster unit; the three future-noise seeds are repeated
measurements. Means receive 10,000-resample cluster-bootstrap intervals. At
least ten validated units are required. Complete unit and task effects are
reported.

## Interpretation

A positive object main effect that exceeds the registered 0.10 donor-steering
effect size, with a small robot-to-goal cross-effect and valid manipulation
checks, supports causal use of task-world future content beyond visible robot
motion. A positive robot effect with null object effect supports prospective
visual inverse dynamics. Either interpretation is about endpoint conditioning,
not planning, search, or goal understanding. Hybrid-state distribution shift,
contact inconsistency, and the absence of a naturally associated action for the
two hybrid cells remain explicit limitations.
